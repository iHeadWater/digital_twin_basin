# 第 4 章 · 监测(Monitoring)

## 本章在课程流水线中的位置

回答"数字孪生体的感知从哪来"。天空地一体化监测是数字流域与物理流域之间的实时纽带:
没有持续观测,孪生体就退化成静态模型。本章承 ch02 的模型与 ch03 的数据组织,
最终为 ch05(案例)提供"活的"观测输入。

- 上一章:[ch03-data](../ch03-data/) —— 数据组织与存储
- 下一章:[ch05-case](../ch05-case/) —— 把模型、数据、监测拼成一个完整案例
- 关联章节:[ch02-models](../ch02-models/) 的评估环节依赖径流观测

## 教学要点

> 占位:随课程推进填充。

- [ ] 天空地一体化:卫星遥感、地面站网、雷达降水的互补
- [ ] 径流观测:水位-流量关系与水文站网
- [ ] 观测数据的不确定性与质量控制
