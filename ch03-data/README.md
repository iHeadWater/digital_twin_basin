# 第 3 章 · 数据(Data)

## 本章在课程流水线中的位置

模型建立之后,回答"数据从哪来、怎么存、怎么喂"。本章直接服务于 ch02 建立的模型接口,
也是 ch04(监测)的上游——监测产生的数据最终都落到本章建立的组织与存储方式上。

- 上一章:[第 3 讲 · 深度学习水文模型](../03-深度学习水文模型/) —— 模型定义了需要什么数据
- 下一章:[ch04-monitoring](../ch04-monitoring/) —— 天空地监测是数据的重要来源
- 公开数据源清单与获取方式见 [data/README.md](../data/README.md)

## 教学要点

> 占位:随课程推进填充。

- [ ] 流域数据的类型:强迫数据(降水/气温)、下垫面属性、径流观测
- [ ] 大数据存储与计算:数据立方体、云存储、并行计算(对应大作业②"水文气象大数据的并行计算实践")
- [ ] 小数据清洗与治理:质量控制、缺失填补、标准化
- [ ] 数据组织与存储方案:按流域、按时间切片的标准格式(CSV / NetCDF / 数据集目录约定)
