# data/ — 输入数据

本目录存放 lab01 的输入数据。

## 现状:合成样例(可直接跑通)

当前目录默认没有提交数据文件。运行一次生成脚本即可得到样例:

```bash
python make_sample.py      # 生成 rainflow_sample.csv
```

`rainflow_sample.csv` 是**合成演示数据**(时间连续、数值规整、无缺测),**不是真实水文观测**。它足够让 lab01 完整跑通:读数据 → 出图 → 对照「下雨→涨水」。绘图格式与真实数据一致,方便之后替换。

## 正式课堂数据(待定)

lab01 正式课堂建议换用一份**真实**的公开测站序列(时间、单位、缺测都真实,才谈得上 lab02 的「质量检查」)。候选来源:

- 本仓库 [data/](../../../../data/) 提供的数据集清单中选一个公开流域/测站;
- CAMELS 等公开数据集子集(下载后按上述表头整理成 CSV);
- 教师随课堂下发的样本文件(放入本目录并更新本说明)。

数据表头约定(与 AGENTS.md 一致,便于学生替换数据后 Agent 无缝工作):

| 列名 | 含义 | 单位 |
|---|---|---|
| `date` | 日期 | `YYYY-MM-DD` |
| `precip_mm` | 日降雨量 | mm/d |
| `flow_m3s` | 日平均流量 | m³/s |

> 替换真实数据时:时间建议连续逐日;允许存在缺测与异常——这正是 lab02 要检查的东西,但请在 AGENTS.md 里如实说明数据缺陷,别让 Agent 瞎猜。
