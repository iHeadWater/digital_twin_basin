# lab01 · 让 AI 画出第一条水文过程线

> 阶段1「让 AI 写代码」——最朴素的一步:AI 可以完成一个**局部任务**。

## 你要做什么

指挥一个终端 AI 编程 Agent,让它读取 `data/` 里的一份降雨 + 流量数据,**画出一张过程线图**(流量为主图、降雨倒置在上),并把图存到 `outputs/`。

## 你会体会

它不是网页聊天框。它真的会:**读文件 → 写代码 → 运行 → 看结果 → 改**。这就是「Agent 能操作你的电脑」的最小证明。

## 环境

- 本仓库已 clone,已进入本目录(`04-hydrology-agent/tutorials/lab01-draw-hydrograph/`)。
- 已装好一个终端 AI 编程 Agent(见 [tutorials/README](../README.md) 前置)。
- 数据:先跑 `data/make_sample.py` 生成一份**合成样例数据**(正式课堂数据见 [data/README.md](data/README.md))。

```bash
cd data && python make_sample.py && cd ..
```

## 步骤

### 1. 在**本目录**启动你的 Agent

把终端 cd 到这个 lab 目录,再启动 Agent:

```bash
# 以 Claude Code / codex / opencode 为例(任选其一)
claude
# 或 codex / opencode
```

> 为什么强调「本目录」:很多 Agent 会**自动读取工作目录里的 `AGENTS.md`**(我们已放好一份),相当于它一进来就知道自己要干嘛。这一步本身就在演示「上下文怎么来」。

### 2. 下第一句指令

给它一句像这样的话(可换成你自己的说法):

> 请读 `data/` 里的降雨和流量数据,画一张逐日过程线:流量用主图,**降雨倒置画在顶部副图**(单位 mm),横轴是时间,把图保存到 `outputs/` 目录,命名 `hydrograph.png`。图里标清楚图例和坐标轴单位。

先别多说——就观察它会怎么一步步做。

### 3. 观察它干活

预期你会看到它大致按这样的顺序:

1. **列出计划**(读数据 → 看结构 → 写绘图脚本 → 跑 → 存图)。
2. **真的去读文件**:`data/` 里的 CSV 长什么样、列名是什么、有没有空值。
3. 写一小段脚本(很可能用 matplotlib / pandas)。
4. 运行,若报错会自己看报错、修改、再跑。
5. 把图写到 `outputs/hydrograph.png`。

> 全程你几乎不用碰代码。这是「指挥」,不是「代写」。

### 4. 验收这张图(检查点)

打开 `outputs/hydrograph.png`,按下面几条自己核,别直接信它说「完成」:

- [ ] 横轴时间是否连续(有没有日期跳空/乱序)?
- [ ] 流量量级合理吗?(对照数据说明的单位;合成数据大约是 m³/s 量级)
- [ ] 降雨是否**倒置**在顶部、与流量趋势大致对应(下雨→涨水)?
- [ ] 坐标轴有单位、有图例、有时间刻度?
- [ ] 图是否真的保存到了 `outputs/`?

如果哪条不对,把问题原样丢给 Agent 让它改,例如:「横轴日期有跳空,检查一下数据是不是有缺测。」

### 5. 复盘三问(写进你的印象里)

1. 和「在网页聊天框里让它写代码、你再自己复制粘贴去跑」相比,这次差在哪?
2. Agent 是怎么知道数据格式的?——是猜的,还是**真的去读了文件**?(第 4 讲要讲「上下文」,这就是活的例子。)
3. 哪一步你仍然需要自己判断?——至少「图对不对」得你说了算。

## 常见坑

| 现象 | 多半是 | 怎么办 |
|---|---|---|
| 图是空的/全黑 | 时间列没解析成日期 | 让它 `print(df.head())`、`df.dtypes` 先自查 |
| 流量数值巨大/离谱 | 单位没对上(如把 m³/s 当成了别的) | 回看数据说明,把单位写进要求 |
| 雨量画成了正立柱状叠在流量上 | 副图没倒置 | 明确「降雨倒置,从上往下」 |
| Agent 一直「计划」不动手 | 模式不对 / 权限受限 | 确认它处于可执行工具的模式;报错贴给它 |
| 图存到了别处 | 没给它明确输出路径 | 自己先建好 `outputs/`,把绝对/相对路径写清楚 |

## 想更进一步(通往 lab02)

加一句让它多做一步——例如:

> 图没问题了。再帮我把数据做个**简单质量检查**:缺测率多少?流量有没有负值?把结果打印出来。

当它能连续完成「读数据 → 检查 → 出图」多步而不需要你一步步喂时,你就摸到 lab02「让 Agent 完成一次分析」的门了。
