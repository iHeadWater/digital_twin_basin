# 第 4 讲 · 实操教程(tutorials)

这一讲不教「点哪个按钮」,而是训练你做专业 AI 工作时代的三件事:**描述任务、验证结果、沉淀方法**。

## 你怎么学(方法约定)

每个 lab 是一个**可独立跟随的任务**。你指挥一个**终端 AI 编程 Agent**(Claude Code / Codex / opencode / DeepSeek Harness 等任意一个,安装见下方前置)去完成一项水文小任务。学完一个 lab,你体会的不只是「AI 会写代码」,而是「Agent 为什么能进入真实工作流」。

```
你(出题 + 验收)
   │ 用自然语言描述任务 / 检查结果
   ▼
AI 编程 Agent
   │ 读文件 / 写代码 / 跑命令 / 改文件
   ▼
你的工作目录(如本 lab 目录)
   ├─ 教程 README.md   ← 你要做什么、看什么、怎么算对
   ├─ AGENTS.md        ← 给 Agent 的任务简报(上下文),它会自动读取
   └─ data/            ← 输入数据与说明
```

> 关键概念体验:把背景写进 `AGENTS.md`、由目录约定兜底,就是给 Agent 喂「准确上下文 + 知识土壤」——这正是第 4 讲要讲清的东西,先动手感受它。

## 前置条件

1. 已完成 [docs/setup](../../docs/setup/) 的 git / ssh / python 环境(第 1 讲布置)。
2. 装好**一个**终端 AI 编程 Agent 并配置好模型:
   - Claude Code / Codex / opencode / DeepSeek Harness 任选其一即可,各 lab 不绑定具体工具;
   - 安装与国内模型配置见语雀[「AI 编程 Agent 工具使用简介」](https://dlut-water.yuque.com/kgo8gd/tnld77/wmcwtsbgux0a3v6q),学校提供的 API 见语雀「大模型厂商 API 配置」。
3. 能读懂降雨/流量过程线,知道 NSE 是什么(第 3 讲内容)——lab02 起会用到。

## 给学生的三条提醒

- **别让它「猜」**:数据在哪、什么单位、要什么格式,写在指令里,或写进 `AGENTS.md`——上下文给得越准,结果越好。
- **别盲信输出**:图要自己看、量级要自己核。lab 的「检查点」就是帮你验收的。
- **报错就贴原话**:Agent 报错就把原始报错丢给它,它能自己诊断。
