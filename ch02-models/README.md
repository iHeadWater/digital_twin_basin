# 第 2 章 · 模型(Models)

## 本章在课程流水线中的位置

课程的技术核心,也是整条流水线的"发动机"。先建立对水文模型的完整认知,
后续章节(数据、监测)都围绕"喂给模型什么、模型输出什么"展开。

- 上一章:[ch01-intro](../ch01-intro/) —— 理念与工具链
- 下一章:[ch03-data](../ch03-data/) —— 模型需要的输入数据如何组织与存储
- 本章产出对"模型输入/输出接口"的定义,是 ch03 与 ch05 的直接输入

## 教学要点

> 占位:随课程推进填充。

- [ ] 水文模型概览:从概念性模型到机器学习模型
- [ ] 可微分模型:把物理过程写进神经网络
- [ ] 深度学习模型:LSTM 流域降雨-径流模拟
- [ ] 模型评估:NSE 等指标,以及"好模型"的标准

### 旧代码提取指南(懒提取)

旧研究仓库 **HydroForecastEval** 已从本仓库退役(备份在教师的其他代码仓库中)。
本章 demo 不重新造轮子,按需提取:

| 需要什么 | 从备份仓库的哪里来 |
|---|---|
| NSE / KGE 等评估函数 | `utils/`、`cal_medium_nse_*.py` |
| LSTM 训练循环 | `scripts/train_lstm_*.py`、`scripts/train_camels*.py` |
| CAMELS / ERA5 数据读取 | `tests/test_dataloader.py`、`tests/test_datasource.py` 所引用的模块 |
| 公开流域清单 | `basinid/camels531.csv` 等公开 ID 清单 |

原则:提取一个 demo 所需的最小集,不为复用而预先包装成框架。
