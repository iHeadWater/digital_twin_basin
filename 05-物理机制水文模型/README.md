# 第 5 讲 · 物理机制水文模型

> 本讲对应课堂 PPT：《物理机制水文模型》。从“一场雨怎样变成流域出口的流量”出发，认识水文模型如何描述产流与汇流，并通过 SCS-CN 模型和单位线理解模型的建立、计算与验证。

## 这一讲你会学到

- 认识水文模型的主要类型，理解集总式、半分布式与分布式模型的区别
- 分清产流与汇流：降雨有多少变成径流，以及这些水怎样到达流域出口
- 以 SCS-CN 为例，理解水量平衡、初损、蓄水能力与径流之间的关系，区分物理约束和经验假设
- 理解前期土壤干湿状态与流域空间差异，怎样影响整体产流响应
- 以单位线为例，理解汇流过程中的延迟、削峰与叠加，初步认识线性水库和 Nash 汇流模型
- 了解参数率定与模型评价，理解为什么拟合得好，还需要独立验证

## 本讲主要内容

### 1. 物理机制水文模型简介

回顾水文模型的发展与分类，认识超渗产流、蓄满产流以及坡面和河网汇流。了解如何利用观测数据率定参数，并从水量、洪峰和峰现时间等方面评价模拟结果。

### 2. 从 SCS-CN 理解产流

从降雨的水量分配出发，逐步理解 SCS-CN 公式及其假设。进一步考虑不同位置的降雨、蓄水容量与前期湿度，认识如何从局地产流汇总得到流域整体响应。

### 3. 从单位线理解汇流

理解有效降雨怎样转化为出口流量过程，学习单位线的平移、缩放与叠加。进一步认识卷积、单位线反求、线性水库与 Nash 模型，以及初始蓄水对后续流量的影响。



> 本讲的重点：既能计算结果，也能说清模型依据了什么、作出了哪些假设，以及这些假设在什么条件下适用。
