# 学生环境准备(第一次上课前完成)

按顺序完成下面两步,即可跑通本课程的全部课堂演示。

| 步骤 | 文档 | 你将完成 |
|---|---|---|
| 1 | [git 与 ssh 配置](git-and-ssh.md) | 安装 git、配置 ssh 密钥、克隆本仓库 |
| 2 | [python 环境搭建](python-env.md) | 安装 miniconda、创建课程 python 环境 |

## 前置要求

- 一台 Windows / macOS / Linux 电脑(文档以 Windows 为例,其他系统命令基本一致)
- 能访问 GitHub(校园网受限时见 git 文档中的「常见问题」)
- 不需要任何编程基础——文档按零基础编写

## 验证你是否准备好了

两步都完成后,在本仓库目录执行:

```bash
git pull
```

没有报错即说明 git / ssh 就绪。python 环境的就绪验证见 [python-env.md](python-env.md) 末尾。

## 遇到问题

- 先查对应文档末尾的「常见问题」
- 仍解决不了:课上带来,或在课程群反馈(有价值的反馈会记入各章 README 的「学生反馈与迭代记录」)
