## Problem Statement

我们如何把一个研究实验废墟仓库(HydroForecastEval,~100 个一次性 LSTM 训练脚本),
重构为《数字孪生流域》课程自己的数字孪生体——**PPT 私有迭代、仓库公开同步、
学生反馈驱动**的课程共建工程现场。

## 核心叙事:仓库 = 这门课的数字孪生

一门数字孪生课程,用它自己教的理念来建设自己:

- **物理实体**(私有):课堂 + 手工 PPT,持续打磨,暂不公开
- **数字孪生体**(公开):本仓库,同步课程结构与素材,对学生可见
- **反馈回路**:学生交互 → 反哺课程体系设计 → 虚实互相打磨

"未定型"不是缺陷,是这门课的建设方式本身。

## 仓库的三个角色

| 角色 | 内容 | 位置 |
|---|---|---|
| 🧪 课程工程现场 | 课程体系设计、学生反馈、迭代记录 | 各章 README「学生反馈与迭代记录」栏 + docs/ideas/ |
| 🎬 OpenMAIC 素材层 | AI 生成课程材料,私有 PPT 的公开补充 | 各章 `素材` 区,上传前过隐私审查 |
| 💻 章节代码演示 | 六章教学代码,逐章生长 | 各章 `demos/` |

## Recommended Direction

**方向三「课程即工程」**。今年先搭全骨架,内容随教学进度逐章填充。

"案例"即贯穿 capstone,是期末演示与大作业的落点。
