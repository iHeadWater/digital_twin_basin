## 教学要点（概念课为主）

- [ ] AI 大模型从「语言生成」走向「任务执行与工具调用」的背景（为第 4 讲 Agent 埋伏笔）
- [ ] 水文模型谱系：概念性模型 → 物理机制模型 → 数据驱动 / 机器学习模型 → 可微分水文模型
- [ ] 物理机制模型与 AI 模型：各自的长处、边界与互补
- [ ] 大样本水文建模：以 Google FloodHub 为代表，说明「用大数据学通用规律」的意义
- [ ] 直接套用到中国流域的问题：区域差异、时间尺度、空间尺度
- [ ] 本土化思路：预训练 / 本地微调、物理机制数据增强、图神经网络汇流等
- [ ] 展望：模型自动率定、规律发现、以 Agent 为接口的未来软件形态（引出第 4 讲）

> 本讲承上启下；深度学习模型如何从数据里学、怎么跑起来，是[第 3 讲](../../03-深度学习水文模型/)的内容，别在这里展开。
