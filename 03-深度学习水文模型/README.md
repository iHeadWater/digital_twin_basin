# 第 3 讲 · 深度学习水文模型

> 呼应 OneDrive PPT《3-深度学习水文模型》。本目录是该讲 PPT 的公开配套层:PPT 讲原理与结构,仓库放能运行的最小 demo 与素材。作业不在此仓库。

## 本讲回答的核心问题

> 给模型过去一段时间的降雨、气象条件和流域属性,它怎样得到未来的流量?

承接第 2 讲(认识了 AI 水文模型的价值),进入「深度学习模型的能力来源」:从数据中学,而不是从公式推。

## 教学要点

- [ ] 贯穿问题:输入(降雨/气温/蒸散/前期状态/流域属性)→ 输出(出口断面流量)
- [ ] 深度学习模型的五种基础能力:表示 / 学习 / 记忆 / 迁移泛化 / 评价可信
- [ ] 为什么需要记忆:水文过程的时间依赖,RNN → LSTM 的存在理由
- [ ] 数据闭环:训练集 / 验证集 / 测试集、过拟合
- [ ] 大样本训练、跨流域泛化、预训练与微调分别解决什么问题(CAMELS 数据集)
- [ ] 评价:会读过程线、NSE、洪峰误差、峰现时间误差
- [ ] 能力边界与可信性:模型在哪些条件下会失效

> 详细的结构、训练与评估演示在 `demos/`;本讲宜配合一个已跑通的最小 LSTM 案例讲「数据 → 模型 → 训练 → 评价」闭环,学生可运行、可改参数。

## demos/(课堂演示 + 学生可运行)

初步规划(承接原模型章 demo 规划):

- 加载预训练 LSTM 模型,现场推理并与实测径流对比(训练过程用日志/动画回放)
- 用公开流域数据跑一个最小 LSTM:改输入窗口 / 训练流域数 / 是否用静态属性,比较结果
- 模型评估:NSE、洪峰误差、峰现时间误差的交互式计算

### 旧代码提取指南(懒提取)

旧研究仓库 **HydroForecastEval** 已退役(备份在教师的其他代码仓库)。本讲 demo 不重造轮子,按需提取:

| 需要什么 | 从备份仓库的哪里来 |
|---|---|
| NSE / KGE 等评估函数 | `utils/`、`cal_medium_nse_*.py` |
| LSTM 训练循环 | `scripts/train_lstm_*.py`、`scripts/train_camels*.py` |
| CAMELS / ERA5 数据读取 | `tests/test_dataloader.py`、`tests/test_datasource.py` 所引用的模块 |
| 公开流域清单 | `basinid/camels531.csv` 等公开 ID 清单 |

原则:提取一个 demo 所需的最小集,不为复用而预先包装成框架。
