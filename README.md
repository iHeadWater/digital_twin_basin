# 《数字孪生流域》课程伴学手册

> 数字孪生流域 · Digital Twin Basin
> 这是你上这门课时的**操作手册**:课前读什么、课上跟着看什么、课后动手练什么,都在这里。PPT 在课堂上讲,仓库陪你把概念变成能做的东西。

---

## 这门课怎么进行

每讲用一个主题 PPT 讲概念与判断;**本仓库按讲次组织**,与该讲 PPT 一一对应。仓库里每个讲次目录通常长这样:

```
02-人工智能与流域水文模型/
├─ README.md          本讲地图:回答什么问题、要做什么(从这开始)
├─ tutorials/         课后动手教程,跟着一步步做(重点)
├─ materials/         与 PPT 互补的公开素材、背景知识
└─ demos/             课堂演示代码
```

一句话分工:**PPT 讲"是什么、为什么",仓库给你"读什么、怎么动手"。**

- 上课要用的代码 / 素材,都在对应讲次目录里
- **作业不在这个仓库**——作业在独立仓库布置与提交,别在这里交
- 课件 PPT 本身不公开;本仓库是它的公开补充层

## 新同学,从这三步开始

1. **装环境**(第 1 讲前完成):[docs/setup/](docs/setup/) 里两步——git/ssh、python 环境
2. **看讲次地图**(下表),认认每讲会讲什么、仓库给什么
3. **跟着一讲走一遍**:打开该讲的 README → 课前看 materials → 课后做 tutorials

## 常见问题(FAQ)

**环境装不上 / 命令跑不通?**
先看对应文档末尾的「常见问题」;教程里报错,把原始报错贴给你的 AI Agent 或直接提 issue。

**某个教程说"规划中/占位"?**
仓库随课程进度逐讲生长,还没到的那讲可能是空壳或 TODO——属正常,不是坏了。

**数据哪来的?能商用吗?**
课堂只用可公开获取的数据,清单见 [data/README.md](data/README.md)。仓库内容许可见文末。

**我想反馈 / 提建议?**
在对应讲次 README 底部的「学生反馈与迭代记录」表留言,或到仓库页提 issue——自愿、不计成绩,反馈会被记录并处理。
