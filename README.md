# 数字孪生流域 · Digital Twin Basin

《数字孪生流域》课程的开源配套项目——**这门课自己的数字孪生体**。

## 这是什么

一门数字孪生课程,用它自己教的理念来建设自己:

- **物理实体**(私有):课堂讲授 + 手工 PPT,持续打磨,暂不公开
- **数字孪生体**(公开):本仓库。课程结构、代码演示、AI 生成素材在此同步
- **反馈回路**:学生反馈进入本仓库,反哺课程体系设计,虚实互相打磨

PPT 课件暂不公开;本仓库是课程的公开补充层。

## 本仓库的三个角色

| 角色 | 说明 | 位置 |
|---|---|---|
| 🧪 课程工程现场 | 课程体系设计的决策留痕与学生反馈迭代 | 各章 README「学生反馈与迭代记录」、[docs/ideas/](docs/ideas/) |
| 🎬 OpenMAIC 素材层 | AI 生成的课程材料,课堂 PPT 的公开补充 | 各章 `materials/` |
| 💻 章节代码演示 | 各章课堂演示代码,逐章生长 | 各章 `demos/` |

## 课程与仓库的对应(2026 秋)

仓库**按讲次组织**:每一讲 PPT 主题对应一个顶层目录。仓库是课程的公开配套层——PPT 讲概念,仓库放学生能跟着动手的**实操教程**与公开素材;作业在独立仓库,不进入本仓库。

| 讲次 | 主题(呼应 PPT) | 仓库配套 |
|---|---|---|
| 1 绪论 | 数字孪生流域理念 + 课程工具链 | 纯讲;配套仅环境准备 [docs/setup/](docs/setup/) |
| 2 | 人工智能与流域水文模型 | [02-人工智能与流域水文模型](02-人工智能与流域水文模型/) |
| 3 | 深度学习水文模型 | [03-深度学习水文模型](03-深度学习水文模型/) |
| 4 | 水文智能体 | [04-水文智能体](04-水文智能体/) —— 实操教程见其 [tutorials/](04-水文智能体/tutorials/) |
| 筹备中 | 数据 / 监测 / 案例 | 尚无目录;待对应 PPT 讲次成型后再按讲次组织新建 |
