# 数字孪生流域 · Digital Twin Basin

《数字孪生流域》课程的开源配套项目——**这门课自己的数字孪生体**。

## 这是什么

一门数字孪生课程,用它自己教的理念来建设自己:

- **物理实体**(私有):课堂讲授 + 手工 PPT,持续打磨,暂不公开
- **数字孪生体**(公开):本仓库。课程结构、代码演示、AI 生成素材在此同步
- **反馈回路**:学生反馈进入本仓库,反哺课程体系设计,虚实互相打磨

PPT 课件暂不公开;本仓库是课程的公开补充层。

## 本仓库的三个角色

| 角色 | 说明 | 位置 |
|---|---|---|
| 🧪 课程工程现场 | 课程体系设计的决策留痕与学生反馈迭代 | 各章 README「学生反馈与迭代记录」、[docs/ideas/](docs/ideas/) |
| 🎬 OpenMAIC 素材层 | AI 生成的课程材料,课堂 PPT 的公开补充 | 各章 `materials/` |
| 💻 章节代码演示 | 各章课堂演示代码,逐章生长 | 各章 `demos/` |

## 课程流水线(2026 秋)

按数字孪生体的构建顺序推进:先建模型,再接数据,再入观测,最后拼成完整案例。

| 章节 | 主题 | 内容 |
|---|---|---|
| [ch01-intro](ch01-intro/) | 绪论 | 数字孪生流域理念 + 课程工具链(git / ssh / python) |
| [ch02-models](ch02-models/) | 模型 | 水文模型:可微分模型与深度学习模型 |
| [ch03-data](ch03-data/) | 数据 | 流域数据的组织与存储 |
| [ch04-monitoring](ch04-monitoring/) | 监测 | 天空地一体化监测与径流观测 |
| [ch05-case](ch05-case/) | 案例 | 贯穿案例:综合前四章,为一个流域搭起迷你数字孪生 |
