# 第 2 讲 · 人工智能与流域水文模型

> 本讲对应课堂 PPT：《人工智能与流域水文模型》。PPT 讲概念与判断，这里给你课前读 + 动手练。

## 这一讲你会学到

- 说清大模型从「聊天」走向「调用工具、执行任务」这一步发生了什么
- 看懂水文模型的谱系：概念性模型 → 物理机制模型 → 数据驱动 / 机器学习模型
- 比较物理机制模型与 AI 模型各自的长处、边界，以及它们为什么互补
- 知道 Google FloodHub 这类"大样本水文建模"在做什么、为什么有意义
- 理解把国外模型/方法搬到中国流域时会遇到哪些问题（区域、时间、空间尺度）
- 了解「预训练 / 本地微调、物理机制数据增强」等本土化思路的由来
- 对第 4 讲的「Agent」先有个感性的样子
